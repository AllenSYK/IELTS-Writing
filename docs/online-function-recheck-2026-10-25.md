## 优先修复的 3 项故障

### P1-01 · 系统设置保存失败：设置参数无效

**复现步骤：**

1. 管理员进入 `/admin/settings`。
2. 保持所有字段原值：Standard、30 天、1 次、14 天、25 条、中文格式、Asia/Shanghai。
3. 点击“保存设置”。

**实际结果：** 先显示“正在保存”，随后提示“设置保存失败 设置参数无效”。页面保存时间未更新。保存前后的输入与选择值逐项对比一致。

**影响：** 管理员无法正常保存现有配置；提示没有指出哪个字段出错，也没有可操作的修正路径。

**建议：** 核对线上客户端实际提交数据与服务端验证规则，特别是版本字段和时间戳格式；将验证失败定位到具体字段。本轮没有取得线上请求体和服务端日志，不能确认唯一根因，也不能直接沿用旧本地代码的归因。

**证据：** [设置保存失败截图](/Users/allen/.codex/visualizations/2026/10/24/01a16baf-0451-7ff0-882a-b4a5d7d38559/online-audit-2026-10-25/admin-settings-save.png)。浏览器日志同时记录 `AdminApiError: 设置参数无效`。

### P1-02 · “我的反馈”无法读取进度

**复现步骤：** 普通用户登录 → 帮助与反馈 → 我的反馈 → 点击“重试”。

**实际结果：** 首次进入和一次重试后均显示“反馈进度读取失败，请稍后重试。”

**影响：** 新增了进度入口，但用户仍无法查询工单状态。即使没有反馈，也应该显示空列表而不是错误。

**已改善部分：** 管理端新增“用户反馈”列表，能打开、筛选，当前显示 0 条；用户端也新增“我的反馈”。因此旧报告中“完全没有入口”的描述不再适用于线上。状态更新、处理结果回传仍未在真实工单上验证。

**建议：** 检查用户侧查询接口、登录身份、字段及数据访问规则，确保有数据和无数据两种情况都能返回正确状态。保留当前明确的错误提示和重试机制。

**证据：** [我的反馈读取失败截图](/Users/allen/.codex/visualizations/2026/10/24/01a16baf-0451-7ff0-882a-b4a5d7d38559/online-audit-2026-10-25/my-feedback-error.png)。

### P1-03 · 已有草稿退出确认未完成跳转

**复现步骤：**

1. 在草稿记录中打开已有的“Academic Task 1 - Map”，原文 193 词。
2. 不编辑正文，点击编辑器顶部“退出”。
3. 在“退出当前写作？”弹窗中点击“退出”。

**实际结果：** 本次内置浏览器会话中，弹窗短暂显示“正在保存草稿…”和“保存中…”，随后恢复原来的确认文案与“退出”按钮；页面仍停留在 `/write/task1?draft=…`。重复一次后仍未完成跳转，没有显示保存失败原因，页面顶部仍显示“已保存”。浏览器未出现额外离开页面确认框。该故障尚需用普通 Chrome 等浏览器交叉验证。

**影响：** 用户无法判断是否保存成功，正常退出路径不可靠。本轮未发现正文丢失，也没有修改正文，不应据此宣称发生了丢稿。

**建议：** 检查保存结果、退出中的状态及最终导航是否正确衔接。验收时分别覆盖有改动、无改动、保存失败、慢网络与计时结束。保存失败应保留明确错误，成功后应可靠返回练习页。

**现场处理：** 选择“留下”关闭确认后，通过直接访问练习页离开了编辑器，未继续重试保存按钮。

**证据：** [编辑器恢复截图](/Users/allen/.codex/visualizations/2026/10/24/01a16baf-0451-7ff0-882a-b4a5d7d38559/online-audit-2026-10-25/user-editor-restored.png)、[退出流程停留截图](/Users/allen/.codex/visualizations/2026/10/24/01a16baf-0451-7ff0-882a-b4a5d7d38559/online-audit-2026-10-25/editor-exit-stuck.png)。
