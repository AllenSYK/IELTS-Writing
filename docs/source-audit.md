# 代码与资源来源审计

## 审计范围

审计覆盖项目维护的 Next.js 页面、组件、服务端路由、工具函数、测试、脚本、SQL、文档和静态资源。

## 结论

- Git 历史显示业务代码在本仓库内持续演进；该事实本身不用于证明外部来源或原创性。
- 未发现指向 Stack Overflow、Gist、博客教程或其他业务项目的来源声明。
- 对具有项目特征的函数名和文本进行了公开精确匹配抽查，未发现可确认的外部同源实现。
- 框架标准写法、Supabase SDK 调用和常见数据处理未被视为来源异常。
- 旧界面层包含工具化命名和旧品牌命名，已改为项目内中性命名。
- 未使用且无归属信息的图片资源已删除。保留的 IELTS SVG 与当前题库数据一致，未发现外部作者、网址或品牌标记。
- 安装包、自动更新和原生授权代码属于已移除的桌面产品范围。

本审计不能证明代码在全球范围内唯一，也不对任何自动检测结果作保证。若后续发现新的授权证据，应按对应许可证补充归属，或根据现有行为规格重新实现相关模块。
