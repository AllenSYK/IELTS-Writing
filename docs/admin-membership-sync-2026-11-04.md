# 管理端会员同步（2026-11-04）

管理端原先仍以激活码和邮箱绑定为主，用户状态只读取历史 profile 字段，无法反映在线订阅、单次付款和试用权益。

本次更新：

- 登录后统一进入管理总览，顶栏和侧栏加入会员管理，移除已停用的生码入口与生码默认值表单。
- 总览接入真实环境的订阅、单次付款、试用预留和待关注订阅记录数；与用户资料和历史绑定分别统计，避免将订单记录数当作去重会员数。
- 新增 `/admin/memberships`，按订阅、单次付款、试用分类分页查看记录，可从用户详情进入指定账号。显示原始订阅状态、已核实权益到期时间、风险暂停、续费状态、真实订单币种金额和最后核实时间。
- 用户列表及详情按用户端现有的历史授权、已付订阅、已核实试用、单次付款顺序计算实际权益。复用现有已付和试用判断，支持1天免绑卡和3天绑卡方案；已取消续费保留当前已付权益，未完成的试用预留不算会员。
- 列表支持按试用、订阅和单次付款会员筛选；总览、会员和用户列表聚焦时重新读取，并每30秒刷新。

接口沿用管理员认证和服务端数据库权限。所有支付查询均限定当前 Stripe 账户及正式／测试环境；只读取已由签名回调或原有核对流程确认的支付状态。不修改支付、价格、试用资格、自动续费或税务设置，无数据库迁移。
