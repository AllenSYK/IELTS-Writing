# 未完成付款拦截试用修复（2026-11-04）

问题：用户打开月度会员收银台后返回网站，Stripe Checkout 仍为 open/unpaid。会员中心的试用预留因原付款占用返回 TRIAL_CHECKOUT_PENDING；刷新状态只重新读取状态，无法解除占用。新错误出现时，之前的“状态已刷新”提示也会继续显示。

修复：试用预留遇到付款占用时，服务端重新核实该客户、Stripe账户及正式/沙盒环境，仅关闭尚未提交且未付款的旧会话，然后按原请求 ID 与会话 ID 比较并更新占用期限，再重试领取。已过期会话只解除占用。已提交、已付款和异步处理中的付款均不自动关闭；创建中的付款没有会话 ID 时也不会强行解除。会话在处理期间完成、网络失败或并发请求改变预留时，停止领取并保留保护。

会员中心开始新操作时清除上次成功提示；“重新核对状态”执行服务端状态同步并清除旧错误，避免成功和失败提示同时残留。

不修改试用天数、每账号一次限制、支付价格或密钥权限；解除旧付款占用本身不会开始或消耗试用。
