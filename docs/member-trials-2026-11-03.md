# 会员访问提示与试用（2026-11-03）

未开通或到期的用户点击受限学习页面时，会员中心读取并校验 next 地址，展示可关闭的居中弹窗，说明目标功能需要会员权益。提供会员方案与两种试用入口。关闭时清除 next 参数，再次点击导航可重新弹出。

## 试用规则

- 免绑卡：1 天，到期自动结束，不自动扣费。服务端通过 Stripe Subscriptions 创建试用，固定 `trial_end` 并设置相同的 `cancel_at`；即使客户已有保存的付款方式也不会自动续费。
- 绑卡：3 天，默认不勾选自动续费。明确同意后才进入 Stripe Checkout，要求收集付款方式；试用后按人民币19.99元/月续费。试用期内可通过会员中心的订阅管理取消续费，剩余试用权益保留至到期。
- 两种方式共用一次机会，按用户 ID、Stripe 账户和正式/沙盒环境唯一约束。数据库预留请求 ID，重试和并发请求使用同一个 Stripe 幂等键。已领取后更换设备、取消订阅或试用到期均不恢复机会。
- 权益由 Stripe 真实订阅状态、服务端预留记录及现有签名 Webhook 共同核实，不以收银台返回参数授予权益。
- 试用状态接入现有页面路由、AI 接口和使用记录，保留正式订阅、单次购买和历史会员的访问逻辑。取消、风控、暂停、过期或未核实的试用不授予权益。

## 配置

追加迁移 `20261103231708_stripe_free_trials.sql`。新增试用预留表只允许 `service_role` 访问；所有新函数使用 `security invoker` 并撤销浏览器角色权限。`STRIPE_TRIAL_ENABLED=false` 可以关闭新领取入口，已生效权益仍按原期限校验。

正式运行密钥必须具有 Subscriptions Write 权限，才能创建1天免绑卡试用；绑卡3天沿用 Checkout 写权限。2026-11-03 经用户确认并完成 Stripe 通行密钥验证后，仅将正式受限密钥的 Subscriptions 从 Read 改为 Write。Stripe 摘要确认其余8项权限保持原值，服务端也已验证写权限生效。不要把密钥发送到聊天或浏览器客户端。

税务维持现有配置；本次未开启 Stripe Tax。如需自动计税，需先核实适用地区和有效税务注册。

官方依据：[Stripe 免费试用](https://docs.stripe.com/billing/subscriptions/trials/free-trials)、[Checkout 免费试用](https://docs.stripe.com/payments/checkout/free-trials)。
