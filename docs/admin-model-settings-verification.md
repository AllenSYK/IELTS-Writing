# 管理端模型配置修复与验证

验证日期：2026-10-24。

## 使用方式

在管理端打开“模型配置”，填写 API 密钥、API Base URL 和各用途的模型名称，先点“测试全部模型”，再点“保存并应用”。支持兼容 Chat Completions 的接口。

- 密钥留空保留原值，输入新密钥即可更换；测试未保存的密钥不会修改数据库。
- 后台密钥使用 AES-256-GCM 加密，接口响应和审计日志不包含密钥或密文。
- 后台配置启用后，题目生成、作文批改、学习计划、图片识别和识别备用均读取后台配置。
- 停用后台配置后使用部署环境变量；未保存后台密钥时使用服务端 `AI_API_KEY`。
- 修复了数据库更新时间微秒精度丢失导致的保存冲突，并保留并发更新保护。

## 真实模型调用的剩余条件

使用当前已保存的接口和模型名称实际请求服务商，五项均返回 `ai_quota_exhausted`（模型服务额度耗尽）。因此，**当前密钥尚不能完成真实业务调用**。需要给服务商账户充值，或在管理端更换有额度且拥有对应模型权限的密钥，再测试五项模型。

可运行 `npm run test:ai-live` 复查当前配置。此命令只读取配置并执行少量模型测试，不修改数据库，不保存业务记录，不输出密钥。

本次修复通过 GitHub 仓库关联的 Vercel 生产项目发布。发布状态以 Vercel 部署记录为准；发布后可在 `/admin/models` 更换密钥并测试。
