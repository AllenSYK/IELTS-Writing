# Web 行为规格

本文件记录 Web 端清理后需要保持的业务行为。

## 身份与授权

- 未登录用户访问受保护页面时跳转到登录页。
- 普通用户登录后进入会员中心；没有会员权益也能查看方案和管理账号资料。
- 管理员账号进入管理后台，不进入普通用户订阅流程。
- 激活码开通、生码和新绑定入口停用，现有历史权益与记录保留。
- 解绑、暂停、过期和撤销状态必须立即影响后续授权检查。

## 题目生成

- 请求必须来自已登录且有有效会员权益的 Web 用户。
- 输入包括任务类型、题型选择和近期题目摘要。
- 服务端校验模型响应的题型与图表结构。
- Mixed Chart 数据不完整时重试一次；仍失败时使用项目内置备用题目。
- 成功和失败请求都记录必要的使用统计，不记录完整作文正文。

## 作文批改

- 请求必须来自已登录且有有效会员权益的 Web 用户。
- 作文长度、任务类型和题目内容在服务端校验。
- 批改结果包含总分、分项评分、摘要、建议和可定位的文本标注。
- 同一页面中的重复提交复用进行中的请求。
- 成功提交写入用户隔离的历史记录和写作活动统计。

## 浏览器数据

- 草稿、历史记录、筛选条件和用户偏好按 Supabase 用户 ID 隔离。
- 旧版本浏览器存储键在首次读取时复制到当前命名空间，避免升级后丢失数据。
- 退出登录只清理当前用户的临时状态，不删除其他账号的数据。
- 重置布局不会删除作文历史、草稿或授权信息。

## 会员中心与支持

- `/billing` 合并会员状态、账号资料、写作活动与订阅管理，使用应用侧栏和内容区布局。
- `/dashboard`、`/settings`、`/activate` 统一重定向到 `/billing`；激活码提交接口返回 410。
- 昵称与平均分编辑只需登录，写入对象只能是服务端认证的当前用户。
- 状态卡展示真实权益，下方玻璃卡片展示价格与续费说明，公开方案页继续保留。
- 支持页只收集浏览器可见的脱敏诊断信息。
- 错误提示不展示密钥、内部数据库对象或完整模型响应。

## 订阅支付

- 月度会员人民币 19.99 元，必须明确确认自动续费后才能进入收银台。
- 所有登录用户均可进入 `/billing`；正式收款配置完成后才开放订阅。
- 付款核对通过 Stripe 签名回调和服务端查询完成，成功 URL 不直接授予权益。
- 相同用户的并发支付请求复用唯一支付会话，不重复创建订阅。
- 取消下一期续费后保留本期已付款权益，续费失败不会延长有效期。
- 全额退款、争议和欺诈预警暂停对应订阅权益；不影响独立有效的历史权益。
- 沙盒和正式环境的客户、订阅及使用权限隔离。
